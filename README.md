Développement web d'une application Touiteur

Ceci est un projet faite au cours d'une SAE qui consiste en une application qui permet la publication de petits textes appelés touites (limités à 235 caractères). 
On peut voir les publications de tous les utilisateurs de l'application et en publier nous-même avec des images et des tags (auxquels on peut s'abonner).

Fonctionnalités :

Afficher la liste touites
Afficher un touite en détail
Afficher les touites d’une personne donnée
Afficher les touites associés à un tag
Publier un touite
La gestion des tags
Le mur d’un utilisateur
Suivre des utilisateurs
S’abonner à un tag
Associer une image à un touite
Les influenceurs
